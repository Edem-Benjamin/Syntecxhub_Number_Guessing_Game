Number Guessing Game

Overview

The Number Guessing Game is a Python-based interactive project developed as part of the Syntecxhub Artificial Intelligence Internship Program. It demonstrates fundamental programming concepts through a simple game in which the player attempts to guess a hidden number.

The project provides practical experience in designing interactive console applications, processing user input, applying conditional logic, and controlling program flow. It serves as a foundation for developing problem-solving skills and understanding how Python can be used to create engaging, logic-driven applications.

Objectives

- Practise fundamental Python programming concepts.
- Develop logical thinking and problem-solving skills.
- Work with user input and conditional statements.
- Understand how loops control repeated interactions.
- Build an interactive application that responds to user decisions.

Technologies Used

- Python — application logic and game implementation.

Key Concepts Demonstrated

- Variables and data types
- User input and output
- Conditional statements ("if", "elif", and "else")
- Loops and repetition
- Comparison operators
- Random number generation, if implemented in the game
- Input validation and basic error handling, if implemented

How to Run

1. Ensure Python is installed on your computer.

2. Clone this repository or download the project files.

3. Open the project folder in your terminal or code editor.

4. Run the Python file containing the game logic:
   
   python number_guessing_game.py
   
   Replace "number_guessing_game.py" with the actual filename in your repository if it differs.

5. Follow the instructions displayed in the terminal to play the game.
